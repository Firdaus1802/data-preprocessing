# Arsip File Eksperimen & Data Mentah

Folder ini menyimpan file-file draf eksperimen, skrip uji coba awal, serta dataset referensi yang digunakan selama proses eksplorasi:

- `arsip_apriori_rules.ipynb`: Draf awal implementasi algoritma Apriori / Association Rule Mining.
- `arsip_bread_basket_draft.ipynb`: Draf eksplorasi awal dataset BreadBasket.
- `arsip_kaggle_market_basket.csv`: Dataset referensi Kaggle Market Basket awal.
- `arsip_kdm_pertemuan6.ipynb`: Materi dan catatan praktikum KDM Pertemuan 6.
- `arsip_market_basket_analysist_raw.xlsx`: File mentah spreadsheet Market Basket Analysis.
- `arsip_market_basket_draft.ipynb`: Draf notebook Market Basket awal.
- `arsip_market_basket_scratch.ipynb`: Catatan skrip scratch pemrosesan data.
- `dataset_retail_bersih.csv`: Sampel draf data ritel bersih.
- `online_retail_raw.csv`: Dataset mentah Online Retail referensi eksternal.
- `arsip_retail_pos_basket_data.csv`: Dataset transaksi ritel POS modern (10.000 baris, 10 atribut).

> Catatan: Dataset mentah berukuran raksasa (`Retail_Transactions_Dataset.csv` 161 MB / 1 juta baris) disimpan secara lokal dan dikecualikan via `.gitignore` guna mematuhi batas ukuran file GitHub (<100 MB).
